# 《实用Python编程》教材与课程主页

## 课程目标

本课程面向零基础学生，培养其面向未来的全栈数据处理与智能应用开发能力。通过本课程的系统学习，学生将建立扎实的计算思维与数据思维，熟练掌握 Python 核心语法及面向对象编程思想；能够独立运用主流第三方库规范完成数据读写、网络数据爬取、数据清洗、NumPy矩阵计算与 Pandas 表格高级分析；掌握传统机器学习（scikit-learn）与现代深度学习（PyTorch）的标准全流程流水线。在此基础上，课程结合以大模型为代表的前沿AI技术，讲授面向大模型辅助编程的结构化提示词编写技巧、基于云端/本地接口进行大模型二次开发（RAG、Agent）等。最终，学生能够在大模型辅助下，独立开发出具有实时交互功能、有一定复杂度的实际工程项目。
